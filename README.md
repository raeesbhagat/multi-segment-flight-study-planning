# W-Pattern and Tag-Flight Study Planning and Exploration

How should a multi-segment study define its comparisons?

This is a public documentation repository for a connected research workstream in Raee Bhagat’s portfolio. It describes methods and decisions from reviewed project materials. It does not contain the original analysis implementation, participant data, or internal research files.

[Portfolio](https://raeeb.dev/) · [Workstream in the project library](https://raeeb.dev/project-library#P11)

## Research context

Developed analysis specifications and exploratory outputs for multi-segment W-pattern and tag-flight operations. The plans define a primary second-leg top-of-descent comparison, secondary longitudinal questions, fatigue endpoints, sleep and recovery measures, and reporting requirements. Visualization notebooks inspect route patterns and performance across segments. This project demonstrates translating stakeholder research questions into implementable analyses and aligning cohort definitions with complex trip structures.

## What the workflow produces

Analysis-planning documents, endpoint definitions, cohort structures, and exploratory plots.

## How to read this workstream

1. Start with the research question: How should a multi-segment study define its comparisons?
2. Read the documented approach above, paying attention to cohort definitions, temporal alignment, repeated observations, and the stated methods where applicable.
3. Evaluate the output in context: Analysis-planning documents, endpoint definitions, cohort structures, and exploratory plots.
4. Separate exploratory or planning work from final conclusions. The repository contains no executable replication or new validation run.
